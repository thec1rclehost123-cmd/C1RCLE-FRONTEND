## Why this sprint looks different from 2026-08-29

A full pass over every backend design/roadmap/status doc and the frontend↔gateway integration
docs turned up two things the last plan didn't account for:

1. **Phase 4 (guest checkout / orders / payments / tickets / discovery) has no HTTP surface.**
   Domain models, application services, adapters and contracts are committed and tested, and
   `CheckoutService` is wired into `apps/api-gateway/src/lib/v2-services.ts` — but **no route file
   for checkout / payments / orders / tickets / wallet / webhooks / public was ever committed.**
   Verified: `a1bd2e7` ("Phase 4 complete") touched only `v2-services.ts` under `apps/`; the route
   files lived only in the working tree destroyed in the 2026-08-28 Windows-junction incident and
   were not part of the `7e2d6c9` recovery. `docs/roadmap/ROADMAP.md` and `phase-04-*.md` still say
   "done, 302 tests pass" — false against the tree.

2. **Backend `pnpm check` is red.** `lint` fails (~900 `no-explicit-any` in `@c1rcle/core`, a
   rushed Phase-5-recovery artifact); `boundaries` fails (raw `fetch()` in
   `packages/core/src/application/payments/razorpay-adapter.ts`); one pre-existing test fails
   (`packages/core/src/infrastructure/compare-and-set.test.ts`). CI can't gate merges until green.

Everything else tracks design: Phases 0–3 live; Phase 5 ≈95 routes live with 6 honest 501s and no
domain-model unit tests; Phases 6–8 are zero backend. Frontend auth infra (`@c1rcle/contracts`,
`@c1rcle/api-client`, `@c1rcle/auth`, the 5-route auth BFF) is merged to `staging`; the 4-lane
de-mock is unstarted.

**Authoritative doc order for any conflict:** master prompt → `C1RCLE-BACKEND/docs/architecture/decisions.md`
→ live code (`route-manifest.ts`, `packages/contracts/src`, `packages/core`) → the FE design spec
→ `C1RCLE-BACKEND/docs/api-contracts/*` → roadmap phase docs → everything else is reference-only.
`FRONTEND-GATEWAY-BACKEND-MAP.md` is the current cross-repo digest.

**Sprint outcome:** green backend CI, honest docs, Phase 4 HTTP surface restored, Phase 5 501s
closed, frontend auth-foundation de-mock landed — leaving Phase 6 (finance ledger) as the next

## Backend front — `C1RCLE-BACKEND` @ `main`

Ground rules unchanged from `FOUNDER-TASKS-2026-08-29.md`: branch off `main`, rebase not merge,
`NODE_OPTIONS=--dns-result-order=ipv4first pnpm check` green before every push, no `--force` /
`--no-verify`. The wire contract is **frozen** for the frontend slice (bare-DTO success, flat
error envelope, `/api/v2/auth/*` as-is, epoch-ms only for `Session.expiresAt` +

not ready ships as an honest 501 with a specific message, never a fake 200. **Never `rm -rf` /
`cp -r` / `git worktree remove` a tree containing `node_modules`** (2026-08-28 incident).
